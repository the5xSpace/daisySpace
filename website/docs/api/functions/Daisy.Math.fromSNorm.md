# Function: fromSNorm()

> **fromSNorm**(`value`, `rangeMaximum?`): `number`

Converts a SNORM value in the range [0, rangeMaximum] to a scalar in the range [-1.0, 1.0].

## Parameters

### value

`number`

SNORM value in the range [0, rangeMaximum]

### rangeMaximum?

`number`

The maximum value in the SNORM range, 255 by default.

## Returns

`number`

Scalar in the range [-1.0, 1.0].
