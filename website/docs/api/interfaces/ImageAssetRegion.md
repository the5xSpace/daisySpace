# Interface: ImageAssetRegion

## Properties

### h?

> `optional` **h?**: `number`

Compatibility alias for `height`.

***

### height?

> `optional` **height?**: `number`

Crop height in source image pixels. `h` is accepted for compatibility.

***

### image

> **image**: `string` \| `HTMLCanvasElement` \| `HTMLImageElement`

Image URL or already-created image element/canvas.

***

### outputHeight?

> `optional` **outputHeight?**: `number`

Optional output canvas height. Defaults to crop height.

***

### outputWidth?

> `optional` **outputWidth?**: `number`

Optional output canvas width. Defaults to crop width.

***

### w?

> `optional` **w?**: `number`

Compatibility alias for `width`.

***

### width?

> `optional` **width?**: `number`

Crop width in source image pixels. `w` is accepted for compatibility.

***

### x

> **x**: `number`

Crop origin X in source image pixels.

***

### y

> **y**: `number`

Crop origin Y in source image pixels.
