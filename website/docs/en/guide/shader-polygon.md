# Shader Polygons

[ShaderPolygonFeature](/en/api/classes/ShaderPolygonFeature) is a polygon-rendering component based on a custom shader pipeline. It supports both ground projection and elevated polygons, making it suitable for coverage areas, geofences, and high-performance batch rendering.

## Basic Usage

Define a polygon with `pathway`, which contains a vertex sequence (`Cartesian3[]`) with at least 3 vertices:

```typescript
import * as Daisy from "daisy-space-sdk"
const engine = await Daisy.Engine.create("daisyContainer")

const entity = engine.createEntity("demo")
entity.position = Daisy.Cartesian3.fromDegrees(116.4, 39.9, 500_000)

entity.addFeature(new Daisy.ShaderPolygonFeature({
    pathway: [
        Daisy.Cartesian3.fromDegrees(90, 20, 0),
        Daisy.Cartesian3.fromDegrees(120, 20, 0),
        Daisy.Cartesian3.fromDegrees(110, 40, 0),
    ],
    color: Daisy.Color.BLUE.withAlpha(0.35),
}))
```

You can also provide geometry through `polygonHierarchy` (`PolygonHierarchy`) or a prebuilt `mesh` (`ShaderPolygonMeshInput`).

## Surface Conformance and Floating

`surfaceConform` controls whether the polygon is projected onto the celestial surface (default: `false`):

```typescript
// 贴地多边形（surfaceConform: true）
new Daisy.ShaderPolygonFeature({
    pathway: positions,
    color: Daisy.Color.fromCssColorString("#2288ff").withAlpha(0.35),
    surfaceConform: true,
})

// 悬浮多边形（surfaceConform: false + height 抬升）
new Daisy.ShaderPolygonFeature({
    pathway: positions,
    color: Daisy.Color.fromCssColorString("#00ddff").withAlpha(0.5),
    surfaceConform: false,
    height: 2000000,   // 高度（米）
})
```

Advanced surface parameters such as subdivision granularity can be controlled with `subdivisionGranularityMeters`, `maxSubdivisionDepth`, and `surfaceErrorMeters`.

## Outlines

```typescript
new Daisy.ShaderPolygonFeature({
    pathway: positions,
    color: Daisy.Color.RED.withAlpha(0.3),
    outline: true,
    outlineColor: Daisy.Color.WHITE,
    outlineWidth: 2,       // 像素
})
```

> **Note:** Outlines are generated by geodesic densification (`_densifyGeodesic`). A large number of edges can significantly affect performance. The ShadePolygonPerf benchmark indicates that enabling outlines can cause a sharp performance decrease.

### Dynamically Updating Outlines

```typescript
// 动态开启或关闭轮廓
feature.setOutline(true, Daisy.Color.WHITE, 1.5)
feature.setOutline(false)
```

## Parallel Mesh Building with Workers

Mesh construction (triangulation and surface subdivision) runs asynchronously in a Web Worker by default, without blocking the main thread:

- All instances share one `sharedMeshBuildWorker` to avoid the overhead of creating duplicate Workers.
- If the Worker fails, construction automatically falls back to the main thread (`meshBuildWorkerFallbackToMainThread = true`).
- You can disable this behavior with `meshBuildInWorker`, although this is generally unnecessary.

This ensures that main-thread rendering is not blocked by mesh construction even when hundreds of polygons are created in a single frame.

## Performance Mode

### Batch Creation

The Perf benchmark Demo (`ShaderPolygonPerf.svelte`) uses **batch creation** to avoid blocking a single frame:

```typescript
const BATCH = 80  // 每批 80 个
function addBatch() {
    const end = Math.min(idx + BATCH, n)
    for (let i = idx; i < end; i++) {
        entity.addFeature(new Daisy.ShaderPolygonFeature({
            pathway: defs[i].pts,
            color: defs[i].color,
        }))
    }
    idx = end
    if (idx < n) setTimeout(addBatch, 0) // 让出主线程
}
```

### Benchmark Data

The `ShaderPolygonPerf` Demo demonstrates rendering **1000 colored polygons** simultaneously (up to 1000 polygons, each with 4 to 8 edges, distributed uniformly over the ellipsoid using the golden angle).

### Performance Notes

| Item | Description |
|------|------|
| Batch creation | Create about 80 polygons per batch and yield to the main thread with `setTimeout(fn, 0)`. |
| Worker mesh building | Enabled by default; triangulation does not block rendering. |
| Avoid large numbers of outlines | Outlines require geodesic densification, which has a significant cost. |
| Control surface subdivision granularity | Avoid setting `subdivisionGranularityMeters` too small. |
| Control the number of polygon edges | More edges per polygon increase triangulation and densification costs. |
