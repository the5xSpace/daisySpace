# Aircraft and Routes

Aircraft is an aviation-specialized Vehicle with a default sensor direction of `TO_BOTTOM` (nadir-facing). Route simulation is implemented via the collaboration of `RouteComponent` + `PathBuilder` + Aircraft.

## Object Hierarchy

```
FreeObject
  └── Vehicle
        └── Aircraft（传感器默认 TO_BOTTOM）
```

Aircraft is itself a physical object that can move along a trajectory. Its position is controlled via `TrajectorySample` / `Cartesian3`; movement capability comes from the trajectory sampling evaluation in the `Vehicle` base class.

## PathBuilder — Path Builder

`PathBuilder` creates a path from a set of waypoints and provides two kinds of output:

| Method | Output | Purpose |
|------|------|------|
| `buildPositions()` | `Cartesian3[]` | Pure position array (polylines, geometry) |
| `buildTrajectory(start, stop)` | `TrajectorySample` | Time-stamped simulation trajectory (drives entity motion) |

### Basic Chaining

```typescript
import * as Daisy from "daisy-space-sdk"
const engine = await Daisy.Engine.create("daisyContainer")

const pts = [
    Daisy.Cartesian3.fromDegrees(116.4, 39.9, 0),   // 北京
    Daisy.Cartesian3.fromDegrees(118.5, 38.2, 0),   // 济南
    Daisy.Cartesian3.fromDegrees(120.8, 31.5, 0),   // 上海
]

// 纯贝塞尔曲线位置
const positions = new Daisy.PathBuilder()
    .fromWaypoints(pts)
    .bezier(20, 30)           // 张力角 20°, 每段 30 采样点
    .buildPositions()

// 带高度剖面的仿真轨迹
const trajectory = new Daisy.PathBuilder()
    .fromWaypoints(pts)
    .bezier(15, 24)
    .setAltitudeProfile({
        segmentAltitudes: [8000, 10000],        // 每段巡航高度（米）
        groundAltitude: 100,
        climbRatio: 0.2,                        // 爬升占 20%
        descentRatio: 0.8,                      // 最后 20% 为下降
    })
    .buildTrajectory(startTime, stopTime, {
        maxSampleIntervalSeconds: 1 / 24,
    })
```

### Interpolation Modes

| Mode | Method | Description |
|------|------|------|
| Bezier (default) | `.bezier(tensionDeg, samples)` | Quadratic Bezier; tension angle controls curvature (5~40°) |
| Geodesic | `.setInterpolation("geodesic")` | Great-circle path (optimal surface route on Earth) |
| Linear | `.setInterpolation("linear")` | Straight line |

### Closed Paths

```typescript
const ring = new Daisy.PathBuilder()
    .fromWaypoints([p1, p2, p3, p4])
    .bezier(15, 20)
    .setClosed(true)
    .buildPositions()
```

## RouteComponent — Route Visualization

`RouteComponent` is an IComponent mounted on `BaseObject`, responsible for drawing the route:

```typescript
const route = new Daisy.PW.RouteComponent({
    waypoints: [
        {
            position: Daisy.Cartesian3.fromDegrees(116.4, 39.9, 0),
            label: "北京",
            subtitle: "首都国际机场 · 起飞",
            popoverContent: "\<div\>ICAO: ZBAA\</div\>",
        },
        {
            position: Daisy.Cartesian3.fromDegrees(120.8, 31.5, 0),
            label: "上海",
            subtitle: "浦东国际机场",
        },
    ],
    lineColor: Daisy.Color.CYAN,
    lineWidth: 2,
    arcType: Daisy.ArcType.GEODESIC,
    curveType: "geodesic",
})

// 挂载到任意 BaseObject
const carrier = new Daisy.PW.FreeObject({ name: "RouteCarrier" })
carrier.bindEngine(engine)
carrier.addComponent(route)
```

### RouteComponentOptions

| Parameter | Type | Default | Description |
|------|------|:---:|------|
| `waypoints` | `RouteWaypoint[]` | — | Waypoint list (at least 2 items) |
| `lineWidth` | `number` | 2 | Line width in pixels |
| `lineColor` | `DColor` | cyan | Line color |
| `curveType` | `"geodesic" \| "bezier"` | bezier | Actual curve type |
| `arcType` | `ArcType` | GEODESIC | Line interpolation mode |
| `clampToGround` | `boolean` | false | Clamp to ground; only effective when `curveType: "geodesic"` |
| `showLine` | `boolean` | true | Show the connecting line |
| `showLabels` | `boolean` | true | Show waypoint labels |
| `showIcons` | `boolean` | true | Show waypoint icons |
| `iconScale` | `number` | 1.0 | Icon scale |
| `labelFont` | `string` | "13px sans-serif" | Label font |
| `popoverTrigger` | `"always" \| "click" \| "hover"` | hover | Popover trigger mode |
| `bezierTension` | `number` | 5 | Bezier tension angle |
| `bezierSamples` | `number` | 24 | Bezier samples per segment |

When `curveType` is `"bezier"`, the path is generated by `PathBuilder`; `arcType` and `clampToGround` do not participate in path construction.

### RouteWaypoint

| Field | Type | Description |
|------|------|------|
| `position` | `Cartesian3` | Waypoint coordinates |
| `label` | `string` | Main title |
| `subtitle` | `string` | Subtitle |
| `icon` | `string` | Custom icon URL |
| `popoverContent` | `string` | HTML popover content |

## Aircraft

```typescript
const aircraft = new Daisy.PW.Aircraft({
    name: "UAV-1",
    position: Daisy.Cartesian3.fromDegrees(116.4, 39.9, 10000),
    point: { size: 1000, color: Daisy.Color.ORANGE },
    text: { text: "UAV-1" },
})

aircraft.bindEngine(engine)

// 设置运动轨迹
aircraft.position = trajectory  // TrajectorySample from PathBuilder
```

Aircraft defaults to sensor direction `TO_BOTTOM`, which can be overridden via `addSensor`'s `emitDirection`.

## Full Route Simulation Example

```typescript
// 步骤 1: 构建轨迹
const waypoints = [
    Daisy.Cartesian3.fromDegrees(116.4, 39.9, 0),
    Daisy.Cartesian3.fromDegrees(118.5, 38.2, 0),
    Daisy.Cartesian3.fromDegrees(120.8, 31.5, 0),
]

const trajectory = new Daisy.PathBuilder()
    .fromWaypoints(waypoints)
    .bezier(15, 30)
    .setAltitudeProfile({
        segmentAltitudes: [8000, 10000],
        climbRatio: 0.2,
        descentRatio: 0.8,
    })
    .buildTrajectory(engine.getStartTime(), engine.getStopTime())

// 步骤 2: 创建航路可视化
const route = new Daisy.PW.RouteComponent({
    waypoints: waypoints.map((pos, i) => ({
        position: pos,
        label: ["北京", "济南", "上海"][i],
        subtitle: `航点 ${i + 1}`,
    })),
    lineColor: Daisy.Color.CYAN,
    lineWidth: 2,
})

const carrier = new Daisy.PW.FreeObject({ name: "Route" })
carrier.bindEngine(engine)
carrier.addComponent(route)

// 步骤 3: 创建飞行器并跟随
const aircraft = new Daisy.PW.Aircraft({
    name: "Airbus",
    position: trajectory,
    point: { size: 1000, color: Daisy.Color.ORANGE },
})
aircraft.bindEngine(engine)

// 步骤 4: 相机跟踪
engine.camera.followTarget(aircraft)
```
