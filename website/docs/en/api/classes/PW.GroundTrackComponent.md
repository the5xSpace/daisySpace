# Class: GroundTrackComponent

PhysicalWorld base class for ground track components.

Components describe "physical semantic capabilities" (e.g. sensors, payloads, control systems, etc.) and are managed through the PW.BaseObject lifecycle.

Design notes:
- Components are not directly exposed as objects to SDK external consumers
- Components can internally hold/drive one or more Features as a rendering adaptation layer
