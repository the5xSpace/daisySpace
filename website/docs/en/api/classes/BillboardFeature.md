### update()

> **update**(`entity`, `time`): `void`

Per-frame update.

Update order (minimizing surprises from a “lifecycle correctness” perspective):
1. Guard check: return immediately if the node is not created
2. Sync node reference and delegate to base class update (handles visibility/LOD/interaction, etc.)
3. Early return if hidden this frame (avoid unnecessary computation)
4. Update world position: entity current position + options.position (entity local offset)
5. Update runtime-modifiable fields such as scale/color
6. Handle screen offset:
 - If “meter offset” is provided: convert to pixel offset based on current viewpoint scale
 - Otherwise use pixel offset

#### Parameters

##### entity

[`Entity`](Entity.md)

##### time

`JulianDate`

#### Returns

`void`

#### Overrides

`Feature.update`
