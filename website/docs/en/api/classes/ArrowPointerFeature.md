# Class: ArrowPointerFeature

ArrowPointerFeature: An “arrow line” feature pointing from the current entity to a target.

- Direction/endpoint recalculation only triggers when callback return values change
- `targetSun/targetMoon` use `Utils.getSunPositionECEF/getMoonPositionECEF`
- label (if configured) is fixed at the arrow endpoint

## Example

```ts
const arrow = new ArrowPointerFeature({
 target: someCesiumEntity,
 lengthPx: 100,
 color: Daisy.Color.ORANGE,
 label: { text: "TARGET" }
});
entity.addFeature(arrow);
```
