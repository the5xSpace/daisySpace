# Class: TimeTask\<Ctx\>

Time interval task — triggers callbacks within the `[startJulianTime, endJulianTime]` range.

Lifecycle callbacks:
- `onEnter`: triggered once when simulation time **first** enters the range (once only)
- `onTick`: triggered **every frame** while simulation time is within the range
- `onLeave`: triggered once when simulation time **leaves** the range (once only)

All callbacks are scheduled through the microtask queue, support `async` callbacks, and exceptions are automatically caught without interrupting the scheduler.

## Example

```ts
// 创建一个在 5~20 分钟区间内执行的观测窗口任务
const start = Daisy.JulianDate.addSeconds(sceneStart, 5 * 60, new Daisy.JulianDate());
const end = Daisy.JulianDate.addSeconds(sceneStart, 20 * 60, new Daisy.JulianDate());

const task = new Daisy.TimeTask({
 id: "observation",
 name: "观测窗口",
 startJulianTime: start,
 endJulianTime: end,
 onEnter: (curTime, ctx, getStartOffset) => {
 console.log("进入观测窗口，偏移:", Math.round(getStartOffset()), "s");
 },
 onTick: (curTime, ctx, getStartOffset, getEndOffset) => {
 // 每帧执行，可用于更新 UI 或检查条件
 },
 onLeave: (curTime, ctx, getStartOffset, getEndOffset) => {
 console.log("离开观测窗口");
 },
});

engine.timeSchedule.add(task);
```
