## Properties

### autoHeight

> **autoHeight**: `number` = `0`

Last calculated "auto length" (unit: meters).

Semantics:
- When emitDirection=TO_GROUND: indicates "ground extension length" (from emitter to ground)
- When trackingTarget exists: indicates the distance from "host to target"

Note: autoHeight is the calculated result, not equivalent to options.height (options.height is the base length).

### calcAutoHeight()

> **calcAutoHeight**(`time?`): `void`

Calculate auto length and apply Z-direction scaling.

Prerequisites:
- Entity current position is available

Result:
- Update autoHeight
- If options.height is valid, apply ratio = autoHeight / options.height to Z scaling

Branches:
- When trackingTarget exists:
 - Length directly takes the distance from "emitter point to target"
- emitDirection=TO_GROUND：
 - Sample to get ground footprint point set via make2dFootprintPositions
 - Get stable length via _stableDistanceFromPositions
- When trackingTarget does not exist and non-TO_GROUND:
 - Directly fall back to beamLength / default length

#### Parameters

##### time?

`JulianDate`

#### Returns

`void`

### update()

> **update**(`entity`, `time`): `void`

Per-frame update: responsible for visibility determination, form switching, matrix synchronization, and autoLength/tracking alignment logic.

Core process:
1) Mode consistency: based on the Engine's current 2D/3D state, destroy if existing rendering object form does not match
2) Final visibility inRange:
 - show (Feature configuration) and Entity show (time-varying)
 - distanceDisplayCondition (any camera within distance range)
3) Visibility change: only sync to rendering object when inRange differs from previous frame, and trigger one refresh
4) If invisible: return early to avoid subsequent matrix/geometry calculations
5) Auto alignment: when trackingTarget exists, automatically align the local "emission axis" to the target direction
6) 3D：
 - If not created, create volume representation on demand
 - If already created, sync modelMatrix every frame and call the onAfterApplied hook
 - When autoLength is enabled, update height scaling every frame
7) 2D：
 - Only TO_GROUND needs footprint; create/update footprint on demand

#### Parameters

##### entity

[`Entity`](Entity.md)

##### time

`JulianDate`

#### Returns

`void`

#### Overrides

`BaseSolidFeature.update`
