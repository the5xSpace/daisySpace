# Class: PopoverFeature

PopoverFeature
DOM popover component that binds an HTML element to a 3D Entity and follows the Entity as it moves.
Supports custom positioning direction, styling, fixed dimensions, and automatic show/hide.

Conservative default: most Features require the Entity model matrix.

##### Returns

`boolean`

Whether this Feature requires the Entity to precompute the model matrix each frame.

Features like points, labels, and billboards that only depend on entity position can return false,
