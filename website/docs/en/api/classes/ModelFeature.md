# Class: ModelFeature

glTF/GLB model component (not exposed externally).

Provides:
- Node list reading and node transformations (show/hide, translation, rotation, scale, matrix override)
- Built-in model animation play/stop (based on activeAnimations)

Node transformations exist as “state side effects” and are automatically applied to model nodes on each frame update.

## Examples

```ts
const entity = viewer.createEntity("sat-1");
entity.position = Daisy.Cartesian3.fromDegrees(116.3, 40.05, 500_000);
viewer.camera.flyToTarget(entity, {
 duration: 0.6,
 offset: new Daisy.HeadingPitchRange(
 Daisy.Math.toRadians(20),
 Daisy.Math.toRadians(-45),
 2_500_000
 ),
});

const model = entity.addFeature(new Daisy.ModelFeature({
 url: "/models/ChandraXrayObservatory.glb",
 minimumPixelSize: 64,
 show: true,
}));

model.onload(() => {
 const names = model.getNodeNames();
 if (names.includes("antenna")) {
 model.transformNode("antenna").setShow(false);
 }

 model.transformNode("body")
 .setTranslation(new Daisy.Cartesian3(0, 0, 0.2))
 .setRotationAxisAngleDeg(Daisy.Cartesian3.UNIT_Z, 15)
 .setScale(1.05);
});
```

```ts
const model = entity.addFeature(new Daisy.ModelFeature({ url: "/static/assets/robot.glb" }));
model.onload(() => {
 const anims = model.getAnimationInfos();
 const first = anims[0];
 if (first) {
 model.playAnimation({ index: first.index, loop: Daisy.ModelAnimationLoop.REPEAT, multiplier: 1.0 });
 }
});
```

### getVisualPixelDiameter()

> **getVisualPixelDiameter**(): `number` \| `undefined`

Returns the model's current screen visual diameter in px.

This replicates the Model's minimumPixelSize reference system:
- `boundingSphere` does not include minimumPixelSize;
- `computedScale` is the final scale after scale / minimumPixelSize / maximumScale;
- Attached visual effects like exhaust flames need to use the same pixel reference to avoid distant models being enlarged while flames still display at fixed pixel minimum.

#### Returns

`number` \| `undefined`

***

### getVisualScaleFactor()

> **getVisualScaleFactor**(): `number`

Returns the model's current visual scale factor.

This value is used internally by the SDK to synchronize "attached visual effects on the model" to the model's
minimumPixelSize scaling result, such as rocket exhaust, attitude control nozzles, and other capsule particle effects.

Note: This does not expose the underlying rendering model object externally, only returns a scale factor consumable by Daisy:
- 1 indicates the model is currently rendered at the configured scale;
- Greater than 1 indicates the model is visually enlarged by minimumPixelSize;
- Conservatively returns 1 when internal runtime state is unavailable.

#### Returns

`number`
