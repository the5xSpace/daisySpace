# Class: OrbitElementsViewComponent

Base class for PhysicalWorld components.

Components describe "physical semantic capabilities" (e.g., sensors, payloads, control systems) and are managed by PW.BaseObject with a unified lifecycle.

Design notes:
- Components do not directly expose objects to SDK external consumers
- Components can internally hold/drive one or more Features as a rendering adaptation layer
