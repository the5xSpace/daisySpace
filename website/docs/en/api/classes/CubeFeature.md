## Properties

### autoHeight

> **autoHeight**: `number` = `0`

The most recently calculated "auto length" (unit: meters).

Semantics:
- When emitDirection=TO_GROUND: indicates "groundward extension length" (from emitter to ground)
- When trackingTarget exists: indicates distance from host to target

Note: autoHeight is a calculated result, not equal to options.height (options.height is the base length).

### calcAutoHeight()

> **calcAutoHeight**(`time?`): `void`

Calculates auto length and writes to Z-axis scaling.

Preconditions:
- Entity current position must be available

Results:
- Updates autoHeight
- If options.height is valid, applies ratio = autoHeight / options.height to Z scaling

Branches:
- trackingTarget exists:
  - Length directly takes "emitter to target" distance
- emitDirection=TO_GROUND:
  - Samples ground point set via make2dFootprintPositions
  - Gets stable length via _stableDistanceFromPositions
- trackingTarget does not exist and not TO_GROUND:
  - Falls back to beamLength / default length

#### Parameters

##### time?

`JulianDate`

#### Returns

`void`

`BaseSolidFeature.calcAutoHeight`

### register()

> **register**(`entity`): `CubeFeature`

Registers to the entity and creates 3D volumetric representation when conditions are met.

The logic here leans towards "initialize once":
- Only attempts to create volumetric representation when 3D + height exists
- Pre-calculates once "whether within distance display range" to avoid creating a large number of invisible objects upon registration
- Sets pivot based on emitDirection (center reference for rotation/scaling)

Note:
- 2D footprint creation happens on demand during the update cycle (only created when TO_GROUND and 2D)

#### Parameters

##### entity

[`Entity`](Entity.md)

`CubeFeature`

### update()

> **update**(`entity`, `time`): `void`

Per-frame update: responsible for visibility determination, morphology switching, matrix synchronization, and autoLength/tracking alignment logic.

Core process:
1) Mode consistency: based on Engine current 2D/3D state, destroys if existing rendering object shape mismatches
2) Final visibility inRange:
  - show (Feature config) and Entity show (changes over time)
  - distanceDisplayCondition (any camera hit distance range)
3) Visibility change: only syncs to rendering object when inRange differs from previous frame, triggering one refresh
4) If not visible: early return to avoid subsequent matrix/geometry calculations
5) Auto alignment: when trackingTarget exists, automatically aligns local "emission axis" to target direction
6) 3D:
  - Creates volumetric representation on demand if not created
  - Syncs modelMatrix every frame if created, and calls hook onAfterApplied
  - Updates height scaling every frame during autoLength
7) 2D:
  - Only TO_GROUND needs footprint; creates/updates footprint on demand

#### Parameters

##### entity

[`Entity`](Entity.md)

##### time

`JulianDate`

#### Returns

`void`

#### Inherited from

`BaseSolidFeature.update`
