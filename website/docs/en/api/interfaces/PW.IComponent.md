# Interface: IComponent

PhysicalWorld component interface.

Components carry "physical semantic capabilities" (e.g., sensors, payloads, control systems) and are mounted on BaseObject for unified management:
- register/unregister: bind/unbind the host object
- update: per-frame update (driven by the host object)
- destroy: release resources

## Properties

### transformer

> **transformer**: `Transformer` \| `undefined`

Component-level Transformer (optional).

Recommended for expressing local transforms for “mounting/physical reference”.

***

### type

> `readonly` **type**: `string`

Component type identifier (for retrieving components by type).

Convention: multiple instances of the same component type may exist on an object (distinguished by id).

### resetTemporalState()?

> `optional` **resetTemporalState**(`time?`): `void`
