# Interface: GeoImageryProviderLayerOptions

Layer display parameters used when directly adding an imagery data source.

## Properties

### alpha?

> `optional` **alpha?**: `number`

Layer alpha, `0` for fully transparent, `1` for fully opaque; retains the layer default when not set.

***

### brightness?

> `optional` **brightness?**: `number`

Layer brightness, `1` for original brightness; retains the layer default when not set.

***

### contrast?

> `optional` **contrast?**: `number`

Layer contrast, `1` for original contrast; retains the layer default when not set.
