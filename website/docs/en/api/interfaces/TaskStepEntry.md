# Interface: TaskStepEntry

任务步骤列表中的单条渲染数据。

## Properties

### color

> **color**: `string`

分配给任务的 CSS 颜色字符串。

***

### endTime

> **endTime**: `JulianDate`

任务计划结束时刻。

***

### id

> **id**: `string`

任务唯一标识。

***

### name

> **name**: `string`

任务显示名称。

***

### progress

> **progress**: `number`

当前进度百分比，范围为 0 至 100。

***

### startTime

> **startTime**: `JulianDate`

任务计划开始时刻。

***

### status

> **status**: `TimeTaskStatus`

当前任务状态。
