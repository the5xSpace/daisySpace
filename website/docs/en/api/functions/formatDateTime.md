# Function: formatDateTime()

> **formatDateTime**(`dateTime`, `pattern`): `string`

支持 `YYYY`、`MMM`、`MM`、`M`、`DD`、`D`、`HH`、`H`、`mm`、`m`、
`ss`、`s`、`SSS`、`TZ` 和 `Z`。
