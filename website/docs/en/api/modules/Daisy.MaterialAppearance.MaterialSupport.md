# MaterialSupport

Determines the type of [Material](../classes/Daisy.Material.md) that is supported by a
[MaterialAppearance](../classes/Daisy.MaterialAppearance.md) instance. This is a trade-off between
flexibility (a wide array of materials) and memory/performance
(required vertex format and GLSL shader complexity.
