# Enumeration: ArcType

ArcType defines the path that should be taken connecting vertices.

## Enumeration Members

### GEODESIC

> **GEODESIC**: `1`

Follow geodesic path.

***

### NONE

> **NONE**: `0`

Straight line that does not conform to the surface of the ellipsoid.

***

### RHUMB

> **RHUMB**: `2`

Follow rhumb or loxodrome path.
