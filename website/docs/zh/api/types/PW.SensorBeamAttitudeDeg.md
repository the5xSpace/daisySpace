# Type Alias: SensorBeamAttitudeDeg

> **SensorBeamAttitudeDeg** = `{ azimuthDeg: number; elevationDeg: number; rollDeg: number }`

传感器波束姿态（角度制，单位：deg）。

- `azimuthDeg`：方位角（绕 +Z 旋转）
- `elevationDeg`：俯仰角（抬升/下压）
- `rollDeg`：横滚角（绕光轴旋转）

## Properties

### azimuthDeg

> **azimuthDeg**: `number`

绕局部 +Z 轴旋转的方位角，单位为度。

***

### elevationDeg

> **elevationDeg**: `number`

波束抬升或下压的俯仰角，单位为度。

***

### rollDeg

> **rollDeg**: `number`

绕波束轴旋转的横滚角，单位为度。
