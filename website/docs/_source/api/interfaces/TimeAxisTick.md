# Interface: TimeAxisTick

时间轴刻度信息。

## Properties

### label

> **label**: `string`

刻度标签文本（由 formatTime 格式化）

***

### leftPx?

> `optional` **leftPx?**: `number`

刻度在时间轴内容区内的左侧位置（px），渲染阶段会补齐。

***

### percent

> **percent**: `number`

刻度位置百分比 (0-100)
