# Interface: GeoImageryProviderLayerOptions

直接添加影像数据源时使用的图层显示参数。

## Properties

### alpha?

> `optional` **alpha?**: `number`

图层透明度，`0` 为完全透明，`1` 为完全不透明；未设置时保留图层默认值。

***

### brightness?

> `optional` **brightness?**: `number`

图层亮度，`1` 表示原始亮度；未设置时保留图层默认值。

***

### contrast?

> `optional` **contrast?**: `number`

图层对比度，`1` 表示原始对比度；未设置时保留图层默认值。
