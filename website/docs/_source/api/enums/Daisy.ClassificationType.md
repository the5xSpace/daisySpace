# Enumeration: ClassificationType

Whether a classification affects terrain, 3D Tiles or both.

## Enumeration Members

### BOTH

> **BOTH**: `2`

Both terrain and 3D Tiles will be classified.

***

### CESIUM\_3D\_TILE

> **CESIUM\_3D\_TILE**: `1`

Only 3D Tiles will be classified.

***

### TERRAIN

> **TERRAIN**: `0`

Only terrain will be classified.
