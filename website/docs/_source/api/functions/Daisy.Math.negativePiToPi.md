# Function: negativePiToPi()

> **negativePiToPi**(`angle`): `number`

Produces an angle in the range -Pi <= angle <= Pi which is equivalent to the provided angle.

## Parameters

### angle

`number`

in radians

## Returns

`number`

The angle in the range [`-Math.PI`, `Math.PI`].
