# Function: sign()

> **sign**(`value`): `number`

Returns the sign of the value; 1 if the value is positive, -1 if the value is
negative, or 0 if the value is 0.

## Parameters

### value

`number`

The value to return the sign of.

## Returns

`number`

The sign of value.
