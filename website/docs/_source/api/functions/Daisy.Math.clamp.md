# Function: clamp()

> **clamp**(`value`, `min`, `max`): `number`

Constraint a value to lie between two values.

## Parameters

### value

`number`

The value to clamp.

### min

`number`

The minimum value.

### max

`number`

The maximum value.

## Returns

`number`

The clamped value such that min <= result <= max.
