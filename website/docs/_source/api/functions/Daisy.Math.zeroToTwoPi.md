# Function: zeroToTwoPi()

> **zeroToTwoPi**(`angle`): `number`

Produces an angle in the range 0 <= angle <= 2Pi which is equivalent to the provided angle.

## Parameters

### angle

`number`

in radians

## Returns

`number`

The angle in the range [0, `Math.TWO_PI`].
